# 个人网站设计辅助：从你的风格到你的网站

目的：借用一套成熟的制作流程与设计理念，让用户得到**属于自己风格**的网站，而不是任何示例的拷贝。方法固定，风格可变。

## 铁律
1. 风格只来自用户（关键词、参照、作品、反感），不来自示例。示例只用来说明方法的深度。
2. 不替用户套用示例里的颜色、角色、材质、文案；用户明确要求参考时，只借“方法”，并说明借了什么。
3. 每一步都有产物，下一步基于上一步的产物。
4. 没有的内容写 [待填]；没验证的效果不写成成果。
5. 大方向的风格词本身画不出来，必须收束到一个**视觉锚点**，并由用户确认。

## 七步流程
### 01 访谈与盘点
问：网站给谁看、要达成什么（求职/展示/接单/建立个人品牌）；有哪些作品与内容、各自完成度；喜欢的参照（网站、影视、物件）；不想要的东西（反向清单）；设备、技术栈、时间约束；是否想要角色/IP。
产出：需求清单。

### 02 定位
写清目标用户、网站要同时做到的 3–4 件事，以及明确舍弃什么。
产出：目标与取舍一页纸。

### 03 风格提取与视觉锚点
**3a 关键词落地**：让用户给 3–5 个关键词，逐词追问“它在你眼里长什么样”，再落到可检查的属性：
- 材质隐喻（纸、金属、玻璃、布、仪器面板……）
- 色彩及各色分工（底色、强调色、文字色、点缀色；各用在哪）
- 形状语言（描边、圆角、阴影、网格、留白）
- 光与空间（有无光源、景深、透视强度）
- 字体与排版节奏
- 动效性格（快/慢、弹性/克制、是否会“表演”）
无法落地的词要追问，不要忽略。同时整理反向清单。

**3b 选视觉锚点（最关键的一步）**：从用户的关键词和故事里，挑**一个具体的场景或物件**统领整个网站，其它风格元素只做配角。例：用户说“二次元、电波系、更丰富”，锚点可以是“她在海底给你发电波的电台”；说“安静、仪器感、夜间”，锚点可以是“深夜的观测站”。好锚点要同时满足：
- **具体**：能画出来的东西或地方，不是形容词。
- **有自己的词汇**：能列出至少 5 个它特有的母题（电台 → 载波线、调台、受信、雪花噪点、彩条、示波器、频道号）。
- **和用户/角色的故事相关**：不是随手拼的，能解释“为什么是它”。
- **能对上界面事件**：每个母题都能找到一个界面时刻去承载（见 04）。
自测：把母题逐个对到界面事件上，对不上一半以上，说明锚点太抽象，换一个。
给用户 2–3 个候选锚点和各自的母题清单，由用户拍板；再选一两个**配角母题**补足风格（如番剧的标题卡/弹幕、贴纸的描边与胶带），配角服从锚点，不抢主位。

**3c 参考驱动的迭代**：先拆参考的形状、偏移、层叠、密度、颜色分工和动作节奏，列出“参考在做什么”并映射到界面；只借设计语法，避免复制受保护的角色、标志、构图细节。按问题优先级分轮验证；范围较大时一轮集中改变一类要素，向用户展示变化。高密度界面把装饰和错位放在边缘、缝隙与背景，文字区保持稳定可读；交互时让可操作区域清晰。

产出：用户自己的设计令牌（色板、形状规则、光、字体、动效性格）及“为什么”；选定的视觉锚点、母题清单与配角母题。

### 04 结构与展具
默认三级结构，可按用户内容调整：预告层（只预告）→ 选择层（只管“去哪里”）→ 内容层（作品在这里展开）。
为每类内容选一件属于**用户自己世界观**（即视觉锚点）的“展具”（展示内容的主物件）。共用的是语法而不是外形：居中的主物件、一眼看出能操作、固定的信息条、清晰的导航与页码、与角色或前景发生关系（若有）、至少两层深度。
先写一张“**界面事件 → 锚点表现**”的映射表，再动手：常驻背景、导航、切页（第一次 / 之后）、状态变化、新内容出现、点击、标题、空状态、提示，各对应锚点里的哪个母题。
面板与区块要分层级，不要千篇一律：主角区块最强处理；按内容换材质（日记类做成笔记纸、数据类做成计分板等，取决于锚点）；普通区块用统一语法，但细节（如胶带位置）交替变化。
借鉴：电影的场面调度（mise-en-scène）——换场景仍像同一个世界，因为布景、灯光、站位的语法一致。
**角色与素材协作**：先确定版面与可用空间，再给素材需求写角色特征、逐张重心与姿势、画风、配色、尺寸、透明边距、参考边界及禁止文字/标志。网页统一控制外描边，素材本身不加贴纸边。验收回执逐项写通过、问题和需重做项；如果用于剪影，检查透明通道、三种背景，以及缩到实际尺寸的纯色轮廓。

**角色摆放**：先确认角色能否出血或遮挡及其空间代价；完整露出时避免受裁剪容器约束，尺寸同时受视口宽高限制。检查层叠上下文与实际遮挡；必要时在可见角色的非透明区域采样 `elementFromPoint`，并在滚动和多视口下核对。

产出：结构图、展具清单、每件展具的交互说明、事件映射表。

### 05 参数化与动效
把令牌集中成变量/配置（色、角度、时长、安全区）；为动效设预算与上限：同一时刻只放一个“大”动效，吵的效果只在第一次出现，常驻环境动效只动位移和透明度，画布类动画在页面不可见时暂停，窄屏减量；提供一键暂停并遵从系统“减少动态”；若有角色或素材，保存锚点标记并提供调试模式。
**转场设计**：先拆参考的进入、遮盖、切换、退出阶段及目标节奏；为首次进入和日常切换分别设预算。频繁切换处理过期动画或竞争条件；提供暂停和减少动态的等价降级。透明彩色角色可用 CSS 滤镜得到黑白剪影，先确认 alpha 干净并检查轮廓。未经用户实际体验，不把设计意图写成流畅或满意。

产出：参数表。

### 06 验收
多视口（桌面主流尺寸、笔记本、手机与短屏）无横向溢出；隐藏的场外元素不得撑宽视口；键盘可达、焦点不引起意外滚动；暂停与减少动态能停掉全部动画；浏览器错误日志为空；保留截图与检查记录（含切换过程中的一帧）；检查装饰是否压住按钮、数值等可操作或关键信息；若有多套主题，确认其它主题未被波及；矮屏降级方式如实标注。
补充适配：覆盖用户真实窗口形状、至少一个窄而高视口和一个超宽视口；顶部和滚动后分别检查角色是否遮挡内容、背景是否铺满、装饰是否裁断。真机与未测交互应明确标记，不能由模拟器结果代替。

实现备忘：核对 `background` 覆盖关系、`transform` 建立的层叠上下文、`clip-path` 对外伸装饰的裁切；让动画变换与布局变换互不干扰。桌面应用若每次启动更换端口，应将界面偏好保存在应用侧并安全注入首屏，不把随机来源的 localStorage 当稳定存储。

产出：验收记录。

### 07 交付
交付：策划案（定位、令牌、视觉锚点与母题、结构、展具、事件映射、参数）、验收记录、未验证边界。把用户的风格写在最前面，示例不出现在交付物里，除非用户要求。

## 改造已有网站或主题时
- 先把现状跑起来截图，用一两句话说出“单调/不对”的具体原因（如：区块长一个样、主题装置缩在边角、大部分时间静止、主题词没被视觉化）。
- 保留原有基调和素材，只叠加覆盖规则与新脚本，原规则不删；所有规则限定在该主题的作用域下；只改主题自己的文件。
- 原作出自别人（他人或其他 AI）时，先说明会大改哪些、保留哪些；改前备份，交付附截图，并说明哪些动效只有实际看了才能判断。

- 开始改造前说明拟改范围与可见影响；尊重用户已经作出的授权与项目协作约定，只有实际需要时再请求确认。
- 部署前在目标机器备份，部署后逐文件读回核对；一批相互依赖的素材与代码一起部署。若更改服务端白名单，说明所需重启。



## 反模式
- 直接复用示例的色板、角色、纸卡/胶带等外形
- 只有形容词、没有视觉锚点，装饰东拼西凑
- “文字加贴图”的普通版式，各页没有共用语法
- 所有区块同一种卡片、同一种阴影
- 多个大动效同时上演
- 没有依据的数据、经历、点评
- 只展示结果，不留可检查的产物

- 只借颜色、不拆构图语法；在版面未定前就固化角色素材。
- 只测标准宽度而漏掉用户真实窗口形状；把桌面界面偏好放在随机端口隔离的浏览器来源中。

## 附录：示例案例（仅说明深度，非模板）
一个游戏策划求职站的案例：材质隐喻选了“纸面与笔刷”，落到四色色板、硬投影纸卡与角色导览，三个入口各有展具（旋转展台、策划白板、书架）。另一位用户若说“安静、仪器感、夜间”，同一方法会落到完全不同的令牌（如深色底、细线框、等宽字体、缓慢淡入）。两者共用流程与语法，外观不同。

视觉锚点的案例：一个 AI 角色控制台的主题，用户要“更二次元、更电波系、更丰富”。锚点选“她在海底给你发电波的电台”，母题对到界面上：背景是一圈圈扩散的电波环和上浮气泡；顶栏底边是走动的载波线；她的在线状态用示波器表示（睡着平线、连接中杂波、在线起伏）；她说话时示波器冲峰、话语以弹幕飘过；第一次切到某页出现番剧中插卡，之后切页是雪花加彩条的“调台”；标题做成番剧片名卡；面板用描边、错位实色影和胶带的贴纸语法。番剧和贴纸只是配角，电台统领一切。

### 「潜入」案例：用户选定风格的设计思路

同一套方法在“电台”“纸面”“潜入”三个案例里，落出了完全不同的外观；案例只用来说明方法的深度，不是模板。以下是案例的设计过程和局限，不表示所有效果已在真实环境验证。

## 0. 风格是谁选的(Skill 铁律 1)
风格来自用户:他给了一批"怪盗团游戏菜单"的截图和一段菜单转场视频,并明确说了三件事——**蓝色是主色,其他颜色随意**;要**信息轰炸**,但**杂乱不让人反感**;角色素材等版面到位后再生成。我没有照搬游戏里的任何角色、标志和那个特定的星形花纹(星纹图案是用代码另画的),只借**版面语法**。

## 1. 视觉锚点
**锚点:"潜入前翻看的行动档案和菜单"**——一份被翻开、贴满标签和胶带的情报卷宗,同时又是一个有节奏地切换的行动菜单。

选它的理由:能画出来;"潜入"这个主题词本身就给了故事(大肥鱼要住进别人的 QQ 小号里);而且卷宗的东西天然是"塞满信息但各有各的位置"。

它的母题(都落在界面上,没有纯装饰):
1. **FILE 标签**——黄色斜贴纸,每页一张,写"FILE 04/11 MEMORY",表示这是卷宗的第几份;
2. **剪字拼贴标题**——每个字像从杂志上剪下来的,底色、倾斜、高低各不同(绑匪信的样子);
3. **字带**——斜穿页面的"INFILTRATE ★ 潜入"跑马灯;
4. **靶环与锁链**——总台中心的同心环加交叉锁链,指"目标"和"锁定";
5. **黑杠标题**——压在面板框外的斜切黑块;
6. **胶带**——粉、青条纹,贴在面板角上;
7. **条码、三角警示、星屑**——塞进缝隙的碎片;
8. **剪影**——转场里扫过屏幕的人形(潜入者的影子)。

**配角母题**:贴纸的白边与硬投影(服从卷宗);怪盗菜单的斜切与跳动(服从切页节奏)。没有用来做主位。

## 2. 设计令牌(为什么)
- **色彩分工**:深蓝黑 `#050A24` 做墨色(框、阴影、字带底);主蓝 `#4D6BFE` 做大面积底色和硬阴影;深蓝 `#2B3FB8` 做底部渐暗;青 `#3FD0FF` 做第二强调和交替阴影;白做字和描边;**黄 `#FFD84D`、粉 `#FF6FAE` 只用在小面积**(标签、胶带、角标)。理由:用户要蓝为主,其余随意,所以其他色只当"标点",不分担大面积。
- **形状语言**:面板不是矩形,是**不规则切角多边形**(多边形向外多留 160px,好让朝外伸出的标题、胶带、阴影不被剪掉);黑白双框(4px 黑加 8px 白)加**硬偏移阴影**(16px,奇偶面板交替蓝与青)。理由:硬阴影和双框读起来像"贴上去的纸",符合卷宗。
- **字体与排版**:粗黑体;标题和黑杠整体向左斜 8–14°;数字用另一款粗斜体。标题背后有一个被屏幕边缘切掉一截的巨型描边英文字(如 TAKEOVER),只做背景,不承担信息。
- **光与空间**:没有光源和景深;层次靠"偏移、遮盖、旋转一点点"。对角线分割背景加半调网点,是平面的。
- **动效性格**:快、硬、"砸下来",不做弹性和柔和过渡。

## 3. 界面事件 → 锚点表现
| 事件 | 锚点里的对应物 |
|---|---|
| 常驻背景 | 对角分割的深蓝黑与主蓝、巨型白圆环、半调网点、成团的星屑与碎片 |
| 导航 | 每个选项斜切并错开高度,当前项放大并上扬——像菜单里被选中的那条 |
| 首次进入 | 开场自检页:卡片错位摆放,她站在环里递一封预告信 |
| 离开开场 | **一次性的大动作**:卡片收拢,星纹团盖满屏幕,她张开双臂定格,裂纹放射,碎裂散开 |
| 日常切页 | 她的白色锯齿剪影扫过,后面跟一层错位的黑影;星纹团鼓出盖屏换页,再缩回 |
| 新内容出现 | 新面板依次"砸"进来;标题的字一个个弹出 |
| 状态变化 | 沿用已有的状态点和数值,不额外加表演 |
| 标题 | 剪字拼贴加背后的巨型描边字加 FILE 标签 |
| 空状态 | 斜条纹虚线框(像档案里"此处无记录"),文字直接说明下一步 |
| 提示 | 白色卡片、左侧蓝边、硬阴影;左边探出她的 Q 版小表情,按提示内容换 |
| 角色出场 | 总台:她站在靶环前;其他页:站在页面右侧的一列里,完整露出 |

## 4. 面板分层级(不千篇一律)
- 每页**第一个面板最强**:最大的偏移和旋转、最粗的标题黑杠。
- 奇偶面板:阴影蓝/青交替,胶带粉/青条纹交替,倾斜方向左右交替。
- 内容决定材质:日记类做成笔记纸、数据类做成计分板、空状态做成档案虚线框。
- 鼠标移上去的面板**摆正并略抬高**——乱是静态的,交互时回到可操作的状态。

## 5. "杂乱但不让人反感"的预算
- **乱度分配**:页头外侧、缝隙、背景承担大部分密度;读字区(面板内部、说明句)干净。
- **说明句**下垫一块深色斜块,避免压在碎片上读不清。
- **窄屏不退回平整版**,只减小偏移和碎片数量。
- **自测**:遮住装饰只看文字区能不能轻松读完;缩到 420px 再看一次。

## 6. 动效预算(对照 Skill 第 05 步)
- 最吵的"碎裂"只在**离开开场页这一次**;日常切页大约 0.7 秒内完成。
- 常驻动效很少,以静态版面为主;"关闭动效"开关和系统"减少动态"都会停掉所有动画(已测:关闭后无动画在跑)。
- 连续快速切页有保护,不会停在错误的页。

## 7. 我哪里没做到位(请如实写进案例的"局限")
