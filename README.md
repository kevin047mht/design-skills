# Design Skills · 设计方法库

一组帮助创作者找到自己风格的设计 Skill。目前收录「个人网站设计辅助」，从用户的作品、想法和参照出发，设计有自己视觉语言的个人网站或作品集。

## 现有 Skill

| Skill | 用途 |
| --- | --- |
| [个人网站设计辅助](skills/portfolio-style-design-method/SKILL.md) | 从访谈、风格提取和视觉锚点，到页面结构、动效、验收与交付。 |

方法重在确定一个能画出来的视觉锚点，再将它与界面事件对应。Skill 中的案例用于说明方法；实际视觉风格由使用者决定。

## 快速下载

**[⬇ 下载完整 Skill 仓库（ZIP）](https://github.com/kevin047mht/design-skills/archive/refs/heads/main.zip)**

解压后，在 `skills/portfolio-style-design-method/` 找到 `SKILL.md`，可以直接阅读，也可以按所用 AI 工具的 Skill 安装方式导入整个文件夹。

### Codex

可以在 Codex 中让内置的 `$skill-installer` 从本仓库安装：

```text
使用 $skill-installer 从 kevin047mht/design-skills 安装 skills/portfolio-style-design-method
```

安装后在下一轮对话中使用。也可将 `skills/portfolio-style-design-method` 文件夹复制到自己的 Codex skills 目录（默认 `~/.codex/skills/`），保持文件夹内的 `SKILL.md`。

### Claude Code

将 `skills/portfolio-style-design-method` 文件夹复制到个人目录 `~/.claude/skills/`，或项目中的 `.claude/skills/`。在对话中说明要用 `portfolio-style-design-method` 设计网站。不同工具的加载方式可能不同，请以相应工具的文档为准。

## 怎么使用

例如：

> 使用个人网站设计辅助 Skill，帮我做一个游戏策划作品集。我的关键词是安静、仪器感、夜间，希望先讨论视觉方向。

开始时准备好网站用途、已有作品、喜欢和不喜欢的参考；无需一次准备齐全。实际项目的技术选型、内容和视觉方向仍由使用者决定。
